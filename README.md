# 제천킹스파찜질방 웹사이트

정적 웹사이트입니다. 별도의 프로그램 설치나 서버 없이 파일만 올리면 동작합니다.

---

## 1. 지금 무엇이 있나요

디자인 세 가지를 만들어 두었습니다. **다 열어보시고 마음에 드는 쪽을 고르시면** 나머지는 지우고 선택한 쪽을 다듬습니다.

| 파일 | 디자인 | 느낌 |
|---|---|---|
| `index.html` | **A안 — 레트로 목욕탕** | 80~90년대 동네 목욕탕·이발소 간판 감성. 크림색 종이 바탕에 빨강·파랑 포인트, 옛날 간판 서체, 목욕탕 타일 무늬, 한자 병기 |
| `y2k.html` | **B안 — 현대화** | 2000년대 골격에 요즘 마감. 좌측 사이드바·방문자 카운터·흐르는 공지·NEW는 남기고, 서체·여백·색·모서리·그림자는 현대식으로 |
| `y2k-classic.html` | **B안 원본** | 2000년대 초반 한국 웹사이트를 그대로 재현. 굴림체, 표 레이아웃, 파란 그라데이션 메뉴바, 촘촘한 1px 테두리 |

각 페이지 **왼쪽 아래에 전환 버튼**이 있어 서로 오가며 비교하실 수 있습니다.
디자인을 확정하면 그 버튼과 안 쓰는 파일은 삭제합니다.

### B안이 두 개인 이유

"y2k에서 좀 더 현대로" 요청에 따라 `y2k.html`을 현대화했고, 비교하실 수 있도록 이전 버전을 `y2k-classic.html`로 남겨두었습니다.
현대화 버전은 **레트로 요소를 버린 게 아니라 골라서 남긴** 것입니다 — 좌측 사이드바, LED 방문자 카운터, 흐르는 공지, 반짝이는 NEW, 한자 병기는 그대로 두고 마감만 요즘 방식으로 바꿨습니다.

### 보는 방법

`index.html` 파일을 더블클릭하면 브라우저에서 바로 열립니다.
휴대폰에서 어떻게 보이는지 확인하려면 브라우저 창의 가로 폭을 좁혀보세요.

## 2. 내용 수정하기

### 요금 · 전화번호 · 공지사항

**`data/site-data.js` 파일 하나만** 고치면 A안·B안 양쪽에 동시에 반영됩니다.
메모장이나 텍스트 편집기로 열어서 따옴표 `" "` 안의 글자만 바꾸시면 됩니다.

```js
{ item: "목욕", sub: "대욕장 · 사우나 · 노천탕", adult: "8,000원", child: "7,000원" },
                                                        ↑ 여기만 바꾸면 됩니다
```

⚠️ 쉼표 `,` 와 중괄호 `{ }` 는 지우지 마세요. 지우면 화면이 깨집니다.

**공지사항 추가**는 `notices:` 항목 맨 위에 한 덩어리를 복사해 붙여넣고 내용만 바꾸면 됩니다.
맨 위에 있는 공지에 자동으로 `NEW` 표시가 붙습니다.

**워터슬라이드 시즌이 끝나면** `waterslide` 의 `show: true` 를 `show: false` 로 바꾸세요.
해당 영역과 메뉴가 사이트에서 자동으로 사라집니다.

### 사진

`assets/img/` 폴더에 정해진 이름으로 사진을 넣으면 자동으로 표시됩니다.
어떤 파일 이름이 필요한지는 [assets/img/README.md](assets/img/README.md)에 표로 정리해 두었습니다.

사진이 없는 동안에는 **"여기에 어떤 사진이 들어가는지" 안내 박스**가 대신 나옵니다.
지금 사이트를 열면 보이는 회색 점선 박스가 그것입니다.

## 3. 파일 구조

```
king/
├─ index.html               A안 · 레트로 목욕탕
├─ y2k.html                 B안 · 현대화
├─ y2k-classic.html         B안 원본 · 2000년대 그대로
├─ data/
│   └─ site-data.js         ★ 요금 · 공지 · 전화번호 — 여기만 고치면 됩니다
├─ assets/
│   ├─ css/retro.css        A안 디자인
│   ├─ css/y2k.css          B안(현대화) 디자인
│   ├─ css/y2k-classic.css  B안 원본 디자인
│   ├─ js/main.js           세 디자인 공통 동작
│   └─ img/                 ★ 사진 넣는 곳
├─ ANALYSIS.md              사전 분석 문서
└─ README.md                이 문서
```

## 4. 들어가 있는 내용

- 첫 화면 (규모 · 24시간 · 접근성 · 주차)
- 소개 — 개장 이야기, 외출 후 재입장, 헬스장 무료 이용
- 시설안내 — 아이스방 / 히노키방 / 소금방 / 캡슐방 / 야외 노천탕 / 대욕장 + 부대시설 6종
- 워터슬라이드 (시즌 배너 · 껐다 켤 수 있음)
- 이용요금 — 요금표, 야간할증, 횟수권·정기권
- 이용안내 — 발권부터 이용까지 4단계, 준비물·주차 안내
- 오시는 길 — 지도, 주소, 대중교통, 네이버·카카오 길찾기 버튼
- 제천 여행 — 걸어서 갈 곳 3곳 + 차로 다녀올 관광지 10곳 (사진 · 주소 · 요금 · 운영시간, 사진 크게 보기)
- 공지사항
- **모바일 하단 고정 바** — 전화하기 · 길찾기 · 요금보기

### 검색 대응

네이버·구글 검색에 잡히도록 아래를 넣어두었습니다.

- 검색 결과에 뜨는 제목·설명문
- 카카오톡·문자로 링크 보낼 때 나오는 미리보기 (`og-image.jpg` 필요)
- 구글이 읽는 사업장 정보 (주소·전화·영업시간·가격대) — 검색 결과에 영업시간이 함께 표시됩니다

## 5. 홈페이지를 인터넷에 올리려면

도메인은 저희가 준비합니다. 아래 중 한 곳에 파일을 올리면 됩니다.

- **Netlify / Vercel** — 폴더를 끌어다 놓으면 끝. 무료. 가장 간단합니다.
- **카페24 / 가비아 웹호스팅** — FTP로 파일을 올립니다. 국내 업체라 전화 문의가 가능합니다.

어느 쪽이든 이 폴더의 파일을 **그대로** 올리면 됩니다. 빌드나 컴파일 과정이 없습니다.

## 6. 아직 확인이 필요한 것

사이트에는 임시로 넣어둔 값이 있습니다. 알려주시면 바로 반영하겠습니다.

| 항목 | 현재 상태 |
|---|---|
| 목욕 요금 | ✅ 8,000원 확정 |
| 워터슬라이드 | 7·8월 운영으로 표시. **이용 시간과 요금이 비어 있습니다** |
| 요일별 허브 | 라벤더·블루베리·쑥 세 가지만 표시 중. **7가지 요일 배치**를 주시면 표로 넣겠습니다 |
| 찜질방·소인 요금 | 12,000원 / 11,000원 · 7,000원 — 최신 요금이 맞는지 확인 필요 |
| 횟수권·정기권 | 금액이 최신인지 확인 필요 |
| 층별 배치 | 1층 프런트 / 2층 드라이 / 3층 찜질로 표시 중. **지하 1층 용도** 확인 필요 |
| 식당 메뉴 | 사이트에 아직 없음. 메뉴와 가격을 주시면 추가하겠습니다 |
| 사업자등록번호 | 비어 있음 (표기 권장) |
| 인스타그램 주소 | 비어 있음 |
| 사진 | 전부 자리표시자 상태 |

이 항목들은 `data/site-data.js` 안에 `⚠️` 표시로도 남겨두었습니다.
