# 360도 파노라마 사진 넣는 곳

## 1) 사진 조건

- **정방향 파노라마(equirectangular)** 형식이어야 합니다. 가로:세로 = **2:1** (예: 6000×3000, 4096×2048)
- 확장자는 `.jpg` 를 권장합니다
- 한 장당 **3MB 이하**를 권장합니다. 너무 크면 휴대폰에서 느리게 열립니다
  - 가로 4096px 정도로 줄이면 화질과 속도가 적당합니다

## 2) 파일 넣기

이 폴더(`assets/img/360/`)에 사진을 넣습니다. 파일 이름은 영문·숫자로 지어주세요.

```
assets/img/360/lobby.jpg
assets/img/360/bath.jpg
assets/img/360/herb-bath.jpg
```

## 3) 사이트에 연결하기

`data/site-data.js` 파일을 열어 `tour360` 안의 `panoramas` 를 채웁니다.

```js
panoramas: [
  { name: "1층 로비",    img: "assets/img/360/lobby.jpg" },
  { name: "대욕장",      img: "assets/img/360/bath.jpg" },
  { name: "야외 노천탕", img: "assets/img/360/herb-bath.jpg" },
],
```

- `name` 은 뷰어 아래 **이동 버튼에 표시될 이름**입니다
- 한 장만 넣으면 버튼 없이 그 장면만 나옵니다
- 여러 장을 넣으면 버튼을 눌러 공간을 옮겨 다닐 수 있습니다
- 순서를 바꾸고 싶으면 줄 순서를 바꾸면 됩니다

## 4) 동작 방식

- 마우스로 **끌어서 돌려보기**, 휠로 확대·축소
- 휴대폰에서는 손가락으로 돌리고 두 손가락으로 확대
- 3초간 조작이 없으면 **천천히 자동 회전**합니다
- 오른쪽 위 버튼으로 **전체화면** 전환
- 360 사진이 없을 때는 "준비하고 있습니다" 안내가 대신 나옵니다

> 뷰어 프로그램은 사진이 있을 때만 내려받습니다. 사진을 안 넣으면 사이트가 무거워지지 않습니다.
