## nearby/ — 제천 관광지 사진 (직접 넣지 않아도 됩니다)

`nearby/` 폴더는 **제천시 공식 관광 누리집의 「추천 관광지」에서 받아온 사진**입니다.
직접 찍으실 필요 없이 이미 다 들어 있습니다.

| 파일 | 쓰이는 곳 |
| --- | --- |
| `<이름>-card.jpg` | 카드에 나오는 대표 사진 (760×428) |
| `<이름>-1.jpg` ~ | 사진을 눌렀을 때 넘겨보는 사진들 (긴 변 1200px) |

이름은 `uirimji`(의림지) · `samhan`(삼한의 초록길) · `taksajeong`(탁사정) · `baeron`(배론성지) ·
`bakdaljae`(박달재) · `cheongpung`(청풍문화유산단지) · `cablecar`(청풍호반 케이블카) ·
`oksunbong`(옥순봉 출렁다리) · `cheukbaek`(측백숲으로) · `sanyacho`(제천산야초마을) 입니다.

어떤 사진을 몇 장 쓸지는 [data/site-data.js](../../data/site-data.js)의 `nearby.places` 에서 정합니다.
출처는 제천시 누리집이니, 사이트에 계속 쓰기 전에 제천시청 관광과에 사용 가능 여부를 한 번 확인해 두시면 좋습니다.

## 촬영 팁

- **가로로 찍어주세요.** 세로 사진은 `about.jpg` 하나만 필요합니다.
- 사람이 나오면 좋지만, 얼굴이 알아볼 정도로 크게 나온 경우 반드시 동의를 받아주세요.
- 아이스방은 **눈이 내리는 순간**을 담아야 효과가 큽니다. 조명이 어두우면 밝게 보정해 주세요.
- 노천탕은 낮보다 **해질 무렵**이 훨씬 좋습니다.
- 물놀이 시설은 **위에서 아래로 내려다본 각도**가 규모를 잘 보여줍니다.

## 파일 크기

한 장당 **500KB 이하**를 권장합니다. 사진이 무거우면 휴대폰에서 사이트가 느리게 열립니다.
[squoosh.app](https://squoosh.app) 같은 무료 사이트에서 용량을 줄일 수 있습니다.
